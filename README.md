## 年付到底怎么算钱：月付乘 12 不是折扣价

官网分类页标的是"每月"起价，年付价格要进结算页选计费周期才显示。这一点很关键，因为不少榜单把"月付乘 12"直接写成"年付价"，看着像年度套餐，实际一分钱没省。

按官网月付价乘 12 得到的年度名义成本：

- 英国 TikTok 专用：AUD$130.80
- 洛杉矶静态家宽 / 纽约 Cogent 家宽：AUD$154.80
- 英国原生家宽：AUD$238.80
- 洛杉矶高配定制：AUD$478.80

第三方整理的年付数字能对上这个算法，比如香港某款标 ¥748/年、月付 ¥62.35，洛杉矶某款标 ¥865/年、月付 ¥72.09，乘 12 刚好相等。也就是说，那些"年付价"就是原价，不含任何折扣。

真正的年付折扣来自优惠码。第三方评测给出两个码：`WePCMON90` 用于月付、季付 9 折，`WePCYEAR80` 用于年付 8 折，两个都写成永久循环、续费同价。这类信息只能当线索用，下单时在结算页找到优惠码输入框，填进去点验证，看实际减免金额再付款。

## 超流量会不会停机：限速到 3Mbps 或 5Mbps，不会断网

官网对超量的写法很直接：英国 TikTok 专用"超流量限速 5M"，美国几款"超流量限速 3M"。限速意味着服务继续跑，不会直接关机，也不会额外扣费，速度降到 3–5Mbps 这个量级。

年付用户要算清楚这件事的影响。3Mbps 大概能维持 SSH、监控面板、低频 API 调用，跑直播推流或者大文件同步就不行了，而且限速会持续到下一个计费月流量重置。月流量给的都是 1TB 或 1.5TB 双向，双向计费意味着上传和下载加起来算，直播推流消耗比想象中快。

如果你预计每个月都会贴着流量上限跑，年付一次性付一年，后面十一个月都被限速的概率不低。这种用法更适合月付或季付，随时能换配置。

## 退款窗口 3 天、10GB 流量，这是年付的后悔药

公开评测整理的政策是：3 天内或者累计使用流量不超过 10GB，可以申请原路退款；超出这个范围，按已用比例扣除后退到账户余额，余额不能提现。

## 哪些人不该买 WePC 的年付

**搭网站跑 WordPress 的**。全系最低配 512MB 内存、10GB 硬盘，装完面板和数据库剩不下多少空间，图片一多就紧张。这个配置是给 IP 属性需求准备的，不是给建站流量准备的。

**只想找最便宜年付的**。拿公开价格做个标尺：RackNerd 的 1GB 档在不同促销批次落在 $11–22/年区间；DMIT 的 T1 系列 WEE 款 $36.9/年，走国际线路，超量后限速 50 或 100Mbps 继续跑；DMIT 洛杉矶 CN2 GIA 入门款 LAX.AN4.Pro TINY 是 $88.88/年。WePC 美国入门款年付原价 AUD$154.80，比上面几档都贵，多出来的钱买的是原生 IP 和双 ISP 属性。不需要干净 IP 的人，这笔钱花得没意义。

**要大内存多核的**。官网英美两页最高配是 4 核 6GB、AUD$39.90/月，再往上没有。要跑重负载，这家产品线本身就不覆盖。

**需要国内低延迟但不在意 IP 属性的**。WePC 的 9929、4837 是回程优化，对国内访问有帮助，可同样的线路等级在别家年付产品里价格更低。为线路付费和为 IP 属性付费是两件事，别混着算。

顺带说一个不相关但容易看花眼的产品：第三方评测提到 WePC 有深港移动 IEPL 专线，50Mbps 约 ¥1480/月，按主播数量卖，面向 MCN 机构。个人用户看到这个价格不用纠结，它不在年付 VPS 的选择范围里。

## 常见问题

**支持支付宝付款吗？**
第三方评测写的是支持支付宝、微信、信用卡、PayPal，PayPal 只走澳币结算并需人工审核。以结算页实际出现的支付方式为准。

**年付中途不想用了能退吗？**
3 天内或累计流量不超过 10GB 可申请原路退款；超出后按已用比例扣除，退到账户余额且不能提现。年付金额大，退款条款值得在付款前读一遍。

**月付和年付差多少？**
按第三方的码算，月付 9 折、年付 8 折，以英国 TikTok 专用款为例，一年下来差 AUD$13 左右。折扣幅度不大，先月付验证再转年付更稳。

**优惠码在哪里填？**
结算页有优惠码输入框，填入后必须点验证按钮，页面显示减免金额才算生效。码区分大小写，复制时别多带空格。第三方给的码是否仍有效，以验证结果为准。

**超流量会被停机吗？**
不会。官网标注的是超量后限速，英国 5Mbps、美国 3Mbps，流量下月重置后恢复。
